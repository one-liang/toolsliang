# 由產品自行保存主題偏好，並僅在使用者主動切換後寫入

介面主題偏好只保存在使用者裝置，且必須等到使用者主動切換後才寫入。`@nuxtjs/color-mode` 在首次載入就會把預設值寫進 `localStorage`，而且模組選項只能更換儲存位置、無法關閉這個行為，因此不再使用該模組，改由 `app/features/shell/theme.ts` 這個深 module 自行處理讀取、正規化、切換與保存。

首次繪製前由 `<head>` 內嵌的 bootstrap script 套用已保存偏好，避免主題閃爍。該 script 只讀取 `localStorage`，不寫入任何值；沒有保存偏好時維持 ADR 與 Design System 指定的亮色預設。儲存空間在無痕或受限瀏覽情境可能拋出例外，讀寫都必須安全降級，不得讓介面失效。

主題偏好屬於 ADR-0001 定義的雲端偏好之外的本機介面偏好，不得同步到伺服器或第三方，也不得與工具內容一起保存。若未來要新增跟隨系統設定的選項，必須同時更新這份決策與相關驗收測試，維持「不主動保存」的預設行為。
