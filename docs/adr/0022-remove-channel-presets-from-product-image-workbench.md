# 商品圖工作台移除通路規格

依使用者要求（#107），商品圖工作台不再依各通路的公開規格產生合規主圖。這份決策取代 ADR-0012：工作台不再把輸出分成合規主圖與品牌宣傳圖兩條分支，只負責把多張商品圖去背、套上背景、框版與 Logo，再依需要壓縮；每一張輸出都是品牌宣傳用的圖片，工具不判斷它是否符合任何通路的上架規定。

移除的範圍包括工作台的「這批輸出的用途」選擇、通路規格選單、查核日期與通路公開規格原文連結、版型預覽上的商品佔比與留白輔助框，以及輸出步驟的規則核對結果。這些介面背後的程式一併移除：通路 preset 與其資料模型、規則判定、來源清單、版型步驟依通路容量範圍調整編碼品質的搜尋，以及對應的文案、單元測試與 e2e。工作台的步驟因此固定為匯入、去背（選用）、版型、品牌素材（選用）、壓縮（選用）與輸出，品牌素材與壓縮不會再因用途或通路規定的容量而停用，檔案大小只由壓縮步驟決定。工具說明、常見問題與結構化資料不再提到通路規格或合規主圖。

版型步驟仍使用 `app/features/tools/compliant-product-image/` 裡的版面引擎：`planPlacement` 的幾何計算，以及在 Worker 裡把一張圖放上一張畫布的算繪引擎。畫布尺寸只受所有圖片入口共用的本機處理上限限制。這個資料夾的名稱與識別字暫時不改，留給工作台改版成單一畫面時一併處理。逐項下載與封存檔沿用品牌宣傳圖的檔名（例如 `brand-promo-image-01.jpg` 與 `brand-promo-images.zip`）。

`compliant-product-image` 這個 slug 依 ADR-0011 繼續以未發布狀態留在工具註冊表，ADR-0019 對獨立頁的處理不變。`docs/research/005-compliant-product-image-presets-and-sources.md` 保留作為當時查核的歷史紀錄，不再被程式引用，也不再維護其中的通路規格。

若日後要恢復依通路規格輸出，需要重新查核各通路當下的公開規格，重新決定工作台的輸出目的與介面，並補回規則判定、來源揭露與 e2e 驗證。
