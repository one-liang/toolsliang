# 圖片工具共用批次上限、縮圖列與在裝置上打包的 ZIP

依使用者在 2026-10-16 的回饋（#80、#105），圖片壓縮、人像去背與品牌宣傳圖都要能一次處理一張或多張。批次上限與 ZIP 打包原本只屬於商品圖工作台，現在移到 `app/features/images/`：四個工具用同一組上限（一次 20 張、合計 200 MiB，依裝置記憶體下修，每張仍受共用的單張上限約束），同一個在背景寫 ZIP 的程式（不壓縮、時間戳記固定為 1980-01-01，不寫入裝置時間），以及同一套選圖區、縮圖列與下載元件。訪客在任一個圖片工具都會在同一個地方被擋下，拿到同一種 ZIP。這修正了 ADR-0004「打包只有工作台需要」的前提，但不改變它把工具組合成工作台的決定。

檔名由呼叫的工具決定，共用模組只負責寫入與檢查。獨立工具用「原檔名＋後綴」，重名時依批次順序從 2 起加序號，比對不分大小寫，讓解壓到不分大小寫的磁碟時不會互相覆蓋，也讓下載的檔案能對回原圖。檔名和圖片一樣只在裝置上產生與保存，不會送往任何伺服器（ADR-0001）。商品圖工作台暫時維持「用途＋序號」的命名，改版（#112）時再決定是否改成原檔名。
