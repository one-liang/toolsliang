# 工具內容只在使用者裝置上處理

平台將保護使用者機密作為核心承諾：使用者交付給工具的檔案、圖片、文字與輸出結果均只在瀏覽器與本機裝置處理，不傳送至平台或第三方伺服器。當某項工具無法在這個邊界內可靠完成時，平台應延後或不提供該工具，而不是在未明確告知的情況下改用雲端處理。

平台將「工具內容」與「雲端偏好」視為不同資料：所有工具都允許匿名使用；只有使用者主動登入後，帳號識別、常用工具、語言與介面偏好才會儲存於 Supabase。隱私說明必須分開陳述這兩類資料，不得籠統宣稱「網站不傳輸任何使用者資料」。

首頁與工具導覽的搜尋索引也在瀏覽器內執行，搜尋查詢不傳送至伺服器或分析服務。

檔案型工具的發布條件必須包含自動化網路邊界測試：處理期間不得有含工具內容的 request、log、analytics 或 error payload，Service Worker 也不得快取使用者輸入、輸出或 Auth response。依賴的模型與 WASM 由平台自有 Cloudflare 網域提供，錯誤診斷必須在本機清理後由使用者主動複製。
