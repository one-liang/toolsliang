# 工作天只以政府行政機關辦公日曆表為準

工作天計算的「工作天」只算行政院人事行政總處公告的政府行政機關辦公日曆表上的上班日與補班日，不模擬民間企業、學校或依勞基法排班的出勤，也不開放使用者自訂放假日、上班日或「週六上班」之類的開關。理由是這份表是唯一有一手來源、版本可追溯、而且台灣行事曆已經收錄並驗證過的工作天依據；民間公司是否比照調整放假與補班由各自決定，沒有可以引用的來源，任何預設都會在某些公司給出錯的答案。不開放自訂延續 ADR-0021 下架自訂行事曆的判斷：在這裡加回自訂假日，等於讓同一個工具換個地方回來。代價是民間公司使用者遇到調整放假或補班日時，答案可能和自己的出勤不同，因此頁面沿用台灣行事曆的 `government-agency-scope` 免責，結果落在補班日時也會直接說明。

工作天計算也不是法定期間或訴訟期限的計算。訴願、上訴、催告等期間依民法第 122 條等規定是數日曆天、末日遇休息日才順延，與數工作天是不同的規則，而規格已把行事曆的法律解釋列為範圍外；頁面明說這一點，不提供末日順延模式。

若日後要支援民間出勤或自訂假日，必須先找到可引用的來源或重新評估與台灣行事曆的分工，並同時修訂 CONTEXT.md 的「工作天」定義與本 ADR。
