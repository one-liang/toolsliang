# 自訂模板與品牌素材只儲存在本機

一般工具輸入與輸出不會被自動持久化；使用者可以明確將自訂模板、框版、Logo、簽名與自訂行事曆保存為當前裝置的本機資產，但它們不會被上傳或透過 Supabase 同步。產品必須顯示這些資產的儲存位置與佔用空間，提供清除本機資料的控制，並說明瀏覽器清除、無痕模式與儲存空間回收可能導致資產消失。

補註（#84）：品牌宣傳圖移除了保存素材的入口，工具內不再寫入或讀取框版、Logo 與背景，組合與圖片只在頁面開著時存在；目前也沒有任何工具保存自訂模板。先前已保存的框版、Logo 與背景仍是本機資產：資料庫保留這些資產種類，舊紀錄照常讀得出來，在本機資產頁（`/{locale}/storage/`）列出並可刪除，整體備份也照舊涵蓋它們。本決策對儲存位置、用量顯示與清除控制的要求不變，適用於目前唯一還能保存的簽名（自訂行事曆已依 ADR-0021 下架）。
