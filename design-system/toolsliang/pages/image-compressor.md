# 圖片壓縮工作區

延續 MASTER.md 的工具外殼、Card、Button、Input 與語意色彩。單欄先呈現檔案選擇，再呈現輸出設定；tablet 以上設定與比較預覽使用雙欄。檔案拖曳是附加入口，所有必要操作均可用原生檔案欄位及鍵盤完成。

原圖與輸出以縮圖卡並排比較，各占一欄，375px 也不改成上下堆疊，比較時不必捲動。選好圖片就先出現原圖卡，壓縮完成後輸出卡接在旁邊。卡片是工作區內的次層容器，使用 `border-subtle` 邊界與 `radius-md`；縮圖框高度手機 136px、tablet 以上 200px，圖片依比例縮小、不放大也不裁切，棋盤格只鋪在圖片本身，用來標出真正的透明區域。卡片內以「尺寸」「檔案大小」標籤列出原圖真實尺寸與 KB／MB 大小（`formatStoredSize`），輸出卡另以膠囊標示縮小或增加的百分比；變大時改用提醒色並在卡片下方補一句說明，不只靠顏色。畫面上不顯示 bytes 數字與檔名；下載檔名由原檔名加上 `-compressed` 產生。縮圖直接使用所選檔案的 object URL，換圖、清除與離開工具時釋放。透明度、品質、格式限制用文字說明。

錯誤區域常駐 `role=alert` 並與檔案欄位關聯；HEIC 拒絕後保留檔案欄位焦點。處理進度採不虛構百分比的 indeterminate progressbar，取消按鈕位於工作表單之外的停用範圍。工作表單有 aria-busy，進度與錯誤訊息不置於 busy 範圍中。
