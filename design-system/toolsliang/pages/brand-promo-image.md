# 品牌宣傳圖

延續 MASTER 的工具工作區、表單、按鈕、語意色彩與 4px 間距基線，沒有色彩或字型覆寫。

- 桌面／平板：左側圖層與數字控制，右側組合預覽；手機依 DOM 順序單欄排列。
- 圖層清單由底到頂，選取狀態同時使用 `aria-pressed`、背景與邊框。
- 預覽使用既有 `image-preview-max-height`；原始圖片只在 Worker 解碼與輸出。
- 所有變換有具名數字欄位，位置另有微調按鈕。排序、顯示、移除、保存皆可用鍵盤操作。
- 復原／重做提供按鈕與 Ctrl／⌘ Z、Shift Z；輸入欄位保留原生文字編輯行為。
- 本機資產與組合設定分開；只有主動保存素材寫入本機資料庫。顯示用量並連到既有管理與備份頁。
