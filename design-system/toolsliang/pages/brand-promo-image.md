# 品牌宣傳圖

延續 MASTER 的工具工作區、表單、按鈕、語意色彩與 4px 間距基線，沒有色彩或字型覆寫。

- 第一個畫面：加入圖層、預覽與「產生 PNG／下載 PNG」在 1366×768 與 375×812 不捲動就看得到。預覽高度以 `--promo-stage-max` 依視窗高度收合，視窗矮時縮小預覽，不把主要動作推到下方。
- 桌面／平板（≥768px）：左欄是預覽，捲動時固定在視窗內；右欄依序是加入圖層、動作列與說明、圖層與調整、輸出尺寸。手機依 DOM 順序單欄排列：加入圖層、預覽、動作列、圖層面板。
- 加入圖層是四個並排按鈕（商品圖、背景、框版、Logo），共用一個隱藏的檔案輸入；按鈕名稱含「加入」動詞。
- 動作列：復原／重做是 44px 圖示按鈕（有名稱與 Ctrl／⌘ Z、Shift Z），主要按鈕填滿剩餘寬度；輸出完成後同一位置換成「下載 PNG」，焦點跟著移過去。
- 空白預覽在畫布內說明下一步；有圖層時才顯示圖層面板與拖曳說明。
- 圖層清單由上到下，選取狀態同時使用 `aria-pressed`、背景與邊框。選取的圖層有位置、縮放、不透明度數字欄位，以及上移、下移、移除；預覽獲得焦點後方向鍵可微調。
- 工具不寫入任何本機資料庫；以前保存的素材由本機資產頁管理。
