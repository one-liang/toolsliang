# Tool App Shell overrides

- 桌面左側欄寬 256px、收合 80px，2px 墨色右邊界；亮色使用 `surface`，暗色使用 dark `surface`，不得整片硬編碼黑色，只有目前所在項目以墨色反白。
- 分類標題前有分類平塗色小方塊；工具 icon 放在該分類平塗色的方塊上。
- 工具頁標頭以分類平塗色區塊呈現（`tool-heading--filled`），與首頁分類區塊一致。
- 手機與平板不顯示桌面側欄，改用底部常駐導覽與分類 drawer 入口。
- 工具目錄以分類網格呈現；工具項目左 icon、中央名稱與簡介、右狀態標籤。
- 工具頁主內容只顯示當前工具工作區與必要說明，不使用 prototype 的右側釘選 demo。
- 常用工具檢視（`/tools/?saved=true`）以單欄清單取代分類網格：每列左 icon、中央名稱與簡介，右側為上移、下移與移除三個 icon-only 按鈕；相鄰目標保留間距，清單以 `aria-live` 回報新位置。
- 側邊欄主要連結依序為全部工具、常用工具與本機資產；本機資產頁只在這裡與手機分類 drawer 底部提供入口，不佔用手機底部導覽的四個位置。
- 側邊欄在主要連結之下顯示常用工具區塊；沒有常用工具時顯示一句說明，不顯示空清單。收合時區塊標題與工具名稱改為 sr-only。
- 工具項目的「常用」標籤來自本機常用工具狀態，與 NEW／PRO／熱門並列在同一個標籤位置。
- 目錄頁是預先產生的，常用篩選只能在裝置上判定：常用檢視、側邊欄清單與導覽標示都等本機資料讀取後才呈現。
- 瀏覽器拒絕保存時，常用檢視與工具頁以警示樣式說明清單不會留在這台裝置。
