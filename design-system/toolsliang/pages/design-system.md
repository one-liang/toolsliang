# Design System Page overrides

- 使用正式 token 與同一套 production components，不另外建立展示專用假元件。
- 展示 primitive／semantic colors、typography、spacing、radius、border、shadow、z-index、motion、breakpoints 與 icon 尺寸。
- 品牌主色需明確展示 `#FF8C42`，並說明 light／dark 中可讀文字與 icon 使用 `primary-strong`；英文 specimen 使用本機 Roboto。
- 展示 default、hover、focus、active、disabled、loading、error、success，以及 NEW／PRO／熱門／常用標籤。
- 每個互動範例都可用鍵盤操作，狀態文字不可只靠顏色。
